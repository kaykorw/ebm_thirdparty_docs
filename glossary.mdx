<Tip>
  Fields follow a consistent pattern: abbreviated English words smashed together in camelCase. When in doubt, read it aloud- `bhfId` = "branch ID", `dvcSrlNo` = "device serial number".
</Tip>

## Authentication (Kayko)

| Term | Full Name | Description |
|------|-----------|-------------|
| API key | Business API key | Secret from Kayko **Settings → Enable EBM → Generate API key**. Send as `Authorization: Bearer sk_…` or `x-api-key`. See [API Keys](/concepts/api-keys) |
| `sk_live_…` / `sk_test_…` | Secret key | Plaintext credential shown once at creation. `test` for training businesses |
| `pk_live_…` / `pk_test_…` | Key prefix | Public identifier stored with the hashed secret |
| Scope | API key scope | Permission slice such as `sales`, `items`, `customers` |
| `allowed_ips` | IP whitelist | Optional IPv4/IPv6/CIDR list that may use the key. Empty = all IPs. Managed with the API key. See [API Keys](/concepts/api-keys) |
| `ebm_url` | EBM URL | Business VSDC base URL assigned when EBM is enabled |

## Universal fields (appear on almost every request)

| Acronym | Full Name | Type | Example | Description |
|---------|-----------|------|---------|-------------|
| `tin` | Taxpayer Identification Number | string(9) | `"100027060"` | Your RRA-registered business TIN |
| `bhfId` | Branch ID | string(2) | `"00"` | `"00"` = head office. `"01"`–`"99"` = branch locations |
| `lastReqDt` | Last Request Date/Time | string(14) | `"20250101010000"` | Sync cursor- returns only records changed after this timestamp (`yyyyMMddHHmmss`) |
| `regrId` | Registrant ID | string(20) | `"1"` | User ID of whoever created the record |
| `regrNm` | Registrant Name | string(60) | `"Kayko"` | Name of whoever created the record (max 8 chars for sales) |
| `modrId` | Modifier ID | string(20) | `"1"` | User ID of whoever last modified the record |
| `modrNm` | Modifier Name | string(60) | `"Kayko"` | Name of whoever last modified the record |
| `useYn` | Use Yes/No | string(1) | `"Y"` | `"Y"` = active, `"N"` = inactive |
| `remark` | Remark | string | `null` | Free-text notes |

## Items & products

| Acronym | Full Name | Description |
|---------|-----------|-------------|
| `itemCd` | Item Code | Unique product identifier. See [Items API- item code format](/api/items#item-code-format) |
| `itemClsCd` | Item Classification Code | RRA product category (10 digits) |
| `itemTyCd` | Item Type Code | `"1"` = Raw Material, `"2"` = Finished Product, `"3"` = Service |
| `itemNm` | Item Name | Product display name |
| `itemStdNm` | Item Standard Name | Standardized product name (optional) |
| `orgnNatCd` | Origin Nation Code | Country of origin (e.g. `"RW"` for Rwanda) |
| `pkgUnitCd` | Packaging Unit Code | How the item is packaged (e.g. `"NT"` = Net, `"BX"` = Box) |
| `qtyUnitCd` | Quantity Unit Code | Unit of measure (e.g. `"U"` = Pieces, `"KG"` = Kilogram) |
| `taxTyCd` | Tax Type Code | `"A"` = Exempt, `"B"` = 18% VAT, `"C"`, `"D"` |
| `bcd` | Barcode | Product barcode (EAN/UPC) |
| `dftPrc` | Default Price | Standard unit price |
| `btchNo` | Batch Number | Manufacturing batch identifier |
| `sftyQty` | Safety Quantity | Minimum stock alert threshold |
| `isrcAplcbYn` | Insurance Applicable Y/N | Whether insurance applies (pharmacy) |
| `cpstItemCd` | Composition Item Code | Component item in a BOM |
| `cpstQty` | Composition Quantity | Quantity of component needed |

## Sales & invoices

| Acronym | Full Name | Description |
|---------|-----------|-------------|
| `invcNo` | Invoice Number | Your sequential invoice number |
| `orgInvcNo` | Original Invoice Number | Original invoice (for refunds/copies- references the source sale) |
| `salesTyCd` | Sales Type Code | `"N"` = Normal, `"C"` = Copy, `"T"` = Training, `"P"` = Proforma |
| `rcptTyCd` | Receipt Type Code | `"S"` = Sale, `"R"` = Refund |
| `pmtTyCd` | Payment Type Code | `"01"` = Cash, `"02"` = Credit, `"06"` = Mobile Money, etc. |
| `salesSttsCd` | Sales Status Code | `"02"` = Approved, `"04"` = Canceled, `"05"` = Refunded |
| `pchsSttsCd` | Purchase Status Code | Same progress codes as sales |
| `cfmDt` | Confirmed Date | Validation timestamp (`yyyyMMddHHmmss`) |
| `salesDt` | Sales Date | Date of sale (`yyyyMMdd`) |
| `stockRlsDt` | Stock Released Date | When inventory was deducted |
| `cnclDt` | Cancel Date | Cancellation timestamp |
| `cnclReqDt` | Cancel Request Date | When cancellation was requested |
| `rfdDt` | Refund Date | Refund timestamp |
| `rfdRsnCd` | Refund Reason Code | Why the refund occurred. See [Enumerations](/reference/enumerations) |
| `prcOrdCd` | Purchase Order Code | **Mandatory for business customers**, optional for individuals (v1.0.5+) |
| `prchrAcptcYn` | Purchase Acceptance Y/N | Whether buyer accepted the goods (`"Y"` / `"N"`) |
