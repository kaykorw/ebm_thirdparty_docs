## Prerequisites

- A **Kayko business** account with permission to manage settings
- An approved **EBM 2.1** registration with RRA (TIN, branch ID, device serial number)
- Kayko EBM available for your environment (Local EBM for development)

## Step 1 — Enable EBM and generate an API key

In the **Kayko business dashboard**:

1. Open **Settings**
2. **Enable EBM** for your business
3. **Generate an API key** (service: EBM) and copy the secret immediately

Store the secret as `KAYKO_EBM_API_KEY`. You will send it on Kayko EBM calls:

```http
Authorization: Bearer sk_live_YOUR_SECRET
```

See [API Keys & Authentication](/concepts/api-keys) for scopes, IP allowlists, rotate/revoke, and error codes.

<Warning>
  You cannot create an EBM API key until **Enable EBM** succeeds. The plaintext secret is shown once.
</Warning>

## Step 2 — Set your base URL

Select an **API Environment** from the navbar dropdown (or the playground environment picker). Use that value as `BASE_URL` / `{{baseUrl}}`:

| Environment | When to use |
|-------------|-------------|
| **Local EBM** | Kayko EBM gateway (`http://localhost:3000/ebm`) |

See the [API Playground](/playground/overview) for how examples update when you switch environments.

## Step 3 — Look up customers

With the **Local EBM** environment selected, look up a customer (API key scope **`customers`**):

<CodeGroup>

```bash cURL
curl -X POST "{{baseUrl}}/customers/select" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET" \
  -d '{
    "tin": "100027060",
    "branch_id": "00",
    "customer_tin": "100004527",
    "ebm_url": "http://localhost:8080/rra/ACME01/"
  }'
```

```javascript JavaScript
const data = await fetch(`${BASE_URL}/customers/select`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.KAYKO_EBM_API_KEY}`,
  },
  body: JSON.stringify({
    tin: '100027060',
    branch_id: '00',
    customer_tin: '100004527',
    ebm_url: process.env.EBM_URL,
  }),
}).then((r) => r.json());
```

```json Payload
{
  "tin": "100027060",
  "branch_id": "00",
  "customer_tin": "100004527",
  "ebm_url": "http://localhost:8080/rra/ACME01/"
}
```

</CodeGroup>

Device initialization is `POST /initialize/init` (internal token) — see [Initialization](/api/initialization). Prefer Kayko EBM routes over any direct RRA paths.
