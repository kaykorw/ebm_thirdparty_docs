## Select customer (Kayko EBM)

`POST /customers/select`

<ParamField body="tin" type="string" required>Your 9-digit TIN</ParamField>
<ParamField body="branch_id" type="string" required>2-character branch ID</ParamField>
<ParamField body="customer_tin" type="string" required>Customer TIN to look up</ParamField>
<ParamField body="ebm_url" type="string" required>Business VSDC base URL from Enable EBM</ParamField>

| Request field | VSDC field |
|---------------|------------|
| `tin` | `tin` |
| `branch_id` | `bhfId` |
| `customer_tin` | `custmTin` |

<CodeGroup>

```bash cURL
curl -X POST "{{baseUrl}}/customers/select" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET" \
  -d '{
    "tin": "100027060",
    "branch_id": "00",
    "customer_tin": "100004527",
    "ebm_url": "http://localhost:8080/rra/ACME01/"
  }'
```

```javascript JavaScript
const data = await fetch(`${BASE_URL}/customers/select`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: `Bearer ${process.env.KAYKO_EBM_API_KEY}`,
  },
  body: JSON.stringify({
    tin: '100027060',
    branch_id: '00',
    customer_tin: '100004527',
    ebm_url: process.env.EBM_URL,
  }),
}).then((r) => r.json());
```

```json Payload
{
  "tin": "100027060",
  "branch_id": "00",
  "customer_tin": "100004527",
  "ebm_url": "http://localhost:8080/rra/ACME01/"
}
```

</CodeGroup>

## Save branch customer

<ParamField body="bhfId" type="string" required>Branch ID</ParamField>
<ParamField body="custNo" type="string" required>Your internal customer number</ParamField>
<ParamField body="custTin" type="string" required>Customer TIN</ParamField>
<ParamField body="custNm" type="string" required>Customer name</ParamField>
<ParamField body="adrs" type="string">Address</ParamField>
<ParamField body="telNo" type="string">Phone number</ParamField>
<ParamField body="email" type="string">Email</ParamField>
<ParamField body="useYn" type="string" required>`"Y"` or `"N"`</ParamField>
<ParamField body="regrId" type="string" required>Registrant ID</ParamField>

<ParamField body="modrId" type="string" required>Modifier ID</ParamField>
<ParamField body="modrNm" type="string" required>Modifier name</ParamField>

<CodeGroup>

