Constants are **static, integrator-friendly code tables** served by Kayko. Use them to populate dropdowns for tax types, packaging units, payment methods, stock types, refund reasons, and related fields before you build sales or stock UIs.

Human-readable tax labels such as **B, 18% Taxable** come from these tables and from [Enumerations](/reference/enumerations).

All constant endpoints are **`GET /constants/…`** on the Kayko EBM gateway. Authenticate with your business API key (any scope). Tenant headers are not required for constants. Responses use `{ message: "success", data: [ … ] }`.

Most items are `{ code, sort, name }`. Taxes also include `rate` and `user_defined_code`. Stock types include `direction` (`in` | `out`). Currencies return **RWF first**.

---

## Get Countries

`GET /constants/countries`

Country codes for fields such as `origin_country`.

<ResponseField name="code" type="string">ISO-style country code (e.g. `RW`)</ResponseField>
<ResponseField name="sort" type="integer">Display sort order</ResponseField>
<ResponseField name="name" type="string">Country name</ResponseField>

## Get Taxes

`GET /constants/taxes`

Tax type codes (`taxTyCd`) with rates. Category **B** is standard 18% VAT. **F** is VAT on fuel (18%). **TT** is the tourism tax rate (3%) used on headers, not as a sale line type.

<ResponseField name="code" type="string">Tax type (`A`–`F`, `TT`)</ResponseField>
<ResponseField name="sort" type="integer">Display sort order</ResponseField>
<ResponseField name="name" type="string">Display label</ResponseField>
<ResponseField name="rate" type="number">Tax rate percent</ResponseField>
<ResponseField name="user_defined_code" type="number">User-defined rate mirror</ResponseField>

## Get Notices

`GET /notices`

Requires scope `notices`, plus headers `x-tin`, `x-branch-id`, and `x-last-request-date` (`YYYYMMDDHHmmss`).

Each notice includes `notice_no`, `title`, `content`, `detail_url`, `registrar_name`, and `registered_at`.
