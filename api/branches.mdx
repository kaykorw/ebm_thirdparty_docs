Branch APIs keep your multi-office structure, store user accounts, and (for pharmacies) register insurance companies used at the counter.

Send `x-tin` and `x-branch-id` on every route below. Kayko resolves `ebm_url` from your business after Enable EBM, so you never put it in the JSON body. All routes require a business API key with scope `branch`. Terminology: [Glossary](/reference/glossary).

---

## Get branches

`GET /branches`

Returns the taxpayer’s branch offices so your CIS can stay aligned with RRA’s branch list (spec §3.3.3 branch information sequence). Also requires `x-last-request-date` (`YYYYMMDDHHmmss`).

<ParamField query="start_page" type="string">Optional page start (digits only)</ParamField>
<ParamField query="end_page" type="string">Optional page end (digits only)</ParamField>

```bash
curl -X GET "{{baseUrl}}/branches?start_page=1&end_page=10" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET" \
  -H "x-tin: 100027060" \
  -H "x-branch-id: 00" \
  -H "x-last-request-date: 20250101000000"
```

</ParamField>

## Save branch insurance

`POST /branches/insurances`

In Kayko - RRA documents this endpoint as **pharmacy-only**. It registers an insurance company code, name, and premium rate percent that the branch uses when selling insured goods.

| Field | Required | Meaning |
|-------|----------|---------|
| `insurance_code` | Yes | Insurance company code (max 10). Upstream `isrccCd`. |
| `insurance_name` | Yes | Insurance company name (max 100). Upstream `isrccNm`. |
| `insurance_rate` | Yes | Premium rate from 0 to 100 (for example `20` for 20%). Sent upstream as numeric `isrcRt`. |
| `use` | No | Defaults to `true`. |

```bash
curl -X POST "{{baseUrl}}/branches/insurances" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET" \
  -H "x-tin: 100027060" \
  -H "x-branch-id: 00" \
  -d '{
    "insurance_code": "ISRCC01",
    "insurance_name": "RSSB Insurance",
    "insurance_rate": 20,
    "use": true
  }'
```

### Response

```json
{
  "message": "success",
  "data": null
}
```
