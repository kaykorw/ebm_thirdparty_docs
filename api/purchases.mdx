## Get purchases

Pull sales transactions registered to your TIN that haven't been confirmed yet.

`POST /trnsPurchase/selectTrnsPurchaseSales`

<ParamField body="tin" type="string" required>Your TIN (as the buyer)</ParamField>
<ParamField body="bhfId" type="string" required>Your branch ID</ParamField>
<ParamField body="lastReqDt" type="string" required>Sync cursor</ParamField>

<CodeGroup>

```bash cURL
curl -X POST "{{baseUrl}}/trnsPurchase/selectTrnsPurchaseSales" \
  -H "Content-Type: application/json" \
  -d '{"tin":"999958074","bhfId":"00","lastReqDt":"20240706204443"}'
```

```javascript JavaScript
const { data } = await ebmPost('/trnsPurchase/selectTrnsPurchaseSales', {
  tin: '999958074', bhfId: '00', lastReqDt: '20240706204443',
});
// data.saleList → unconfirmed supplier invoices
```

```php PHP
<?php
$result = ebmPost('/trnsPurchase/selectTrnsPurchaseSales', [
    'tin' => '999958074', 'bhfId' => '00', 'lastReqDt' => '20240706204443',
]);
```

```json Payload
{
  "tin": "999958074",
  "bhfId": "00",
  "lastReqDt": "20240706204443"
}
```

</CodeGroup>

## Save purchase

Confirm a purchase transaction.

`POST /trnsPurchase/savePurchases`

<ParamField body="invcNo" type="number" required>Your purchase invoice number</ParamField>
<ParamField body="orgInvcNo" type="number" required>Original invoice number</ParamField>
<ParamField body="spplrTin" type="string">Supplier TIN</ParamField>
<ParamField body="spplrNm" type="string">Supplier name</ParamField>
<ParamField body="spplrInvcNo" type="string">Supplier's invoice number</ParamField>
<ParamField body="regTyCd" type="string" required>`"A"` Automatic or `"M"` Manual</ParamField>
<ParamField body="pchsTyCd" type="string" required>`"N"` Normal</ParamField>
<ParamField body="rcptTyCd" type="string" required>`"P"` Purchase or `"R"` Refund</ParamField>
<ParamField body="pmtTyCd" type="string" required>Payment method code</ParamField>
<ParamField body="pchsSttsCd" type="string" required>`"02"` Approved</ParamField>
<ParamField body="pchsDt" type="string" required>Purchase date (`yyyyMMdd`)</ParamField>
<ParamField body="itemList" type="array" required>Line items with your `itemCd` mapped</ParamField>
