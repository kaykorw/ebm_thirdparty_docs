All constant endpoints are **`GET /constants/…`** on the Kayko EBM gateway. Authenticate with your business API key (any scope). Tenant headers are not required for constants.

```http
Authorization: Bearer sk_live_YOUR_SECRET
# or
x-api-key: sk_live_YOUR_SECRET
```

Response shape:

```json
{
  "message": "success",
  "data": [ … ]
}
```

Most items are `{ code, sort, name }`. Taxes also include `rate` and `user_defined_code`. Stock types include `direction` (`in` | `out`). Currencies return **RWF first**.

## Select Countries

`GET /constants/countries`

Country codes for fields such as `orgnNatCd`.

<ResponseField name="code" type="string">ISO-style country code (e.g. `RW`)</ResponseField>
<ResponseField name="sort" type="integer">Display sort order</ResponseField>
<ResponseField name="name" type="string">Country name</ResponseField>

<CodeGroup>

```bash cURL
curl -X GET "{{baseUrl}}/constants/countries" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET"
```

```javascript JavaScript
const countries = await fetch(`${BASE_URL}/constants/countries`, {
  headers: { Authorization: `Bearer ${process.env.KAYKO_EBM_API_KEY}` },
}).then((r) => r.json());
```

```php PHP
<?php
$ch = curl_init($baseUrl . '/constants/countries');
curl_setopt_array($ch, [
    CURLOPT_HTTPHEADER => ['Authorization: Bearer ' . getenv('KAYKO_EBM_API_KEY')],
    CURLOPT_RETURNTRANSFER => true,
]);
$countries = json_decode(curl_exec($ch), true);
```

```json Response
{
  "message": "success",
  "data": [
    { "code": "RW", "sort": 193, "name": "RWANDA" },
    { "code": "KE", "sort": 115, "name": "KENYA" }
  ]
}
```

</CodeGroup>

`GET /constants/taxes`

<ResponseField name="code" type="string">Tax type (`A`–`D`)</ResponseField>
<ResponseField name="sort" type="integer">Display sort order</ResponseField>

<ResponseField name="rate" type="number">Tax rate percent</ResponseField>
<ResponseField name="user_defined_code" type="number">User-defined rate mirror</ResponseField>

<CodeGroup>

```bash cURL
curl -X GET "{{baseUrl}}/constants/taxes" \
```

## Select Notices

`GET /notices`

Requires scope `notices`, plus headers `x-tin`, `x-branch-id`, and `x-last-request-date` (`YYYYMMDDHHmmss`).

```bash
curl -X GET "{{baseUrl}}/notices" \
  -H "Authorization: Bearer sk_live_YOUR_SECRET" \
  -H "x-tin: 100027060" \
  -H "x-branch-id: 00" \
  -H "x-last-request-date: 20250101000000"
```

Mapped response:

```json
{
  "message": "success",
  "data": [
    {
      "notice_no": 1,
      "title": "…",
      "content": "…",
      "detail_url": "…",
      "registrar_name": "…",
      "registered_at": "…"
    }
  ]
}
```
