Open this section from the top nav **API Playground** button. Use the **playground sidebar** to pick an endpoint and send live requests — each operation has pre-filled bodies, auth, and response examples.

## Before you start

<Steps>
  <Step title="Pick an environment">
    Use the **environment dropdown** on any playground page:

    | Environment | Use for |
    |-------------|---------|
    | **Local EBM** | Kayko EBM gateway (development) |

    Code samples use `{{baseUrl}}` and update when you switch environments.
  </Step>
  <Step title="Authenticate">
    | Routes | Header |
    |--------|--------|
    | Customers, Reference Data (`/constants/*`), sales, items, … | `Authorization: Bearer sk_…` or `x-api-key: sk_…` |
    | Initialization (`/initialize/*`) | `X-API-Token: <EBM_INTERNAL_API_TOKEN>` |

    Generate business keys in the dashboard: **Settings → Enable EBM → Generate API key**. See [API Keys](/concepts/api-keys).
  </Step>
  <Step title="Set ebm_url on proxied POSTs">
    Device init and customer routes need `ebm_url` in the JSON body (from Enable EBM), for example:

    ```
    http://localhost:8080/rra/{business_code}/
    ```
  </Step>
  <Step title="Send">
    Edit the pre-filled body, then click **Send**. Inspect status, headers, and response body in the panel.
  </Step>
</Steps>

## What responses look like

| Kind | Shape |
|------|-------|
| `/initialize/init` | Full envelope `{ resultCd, resultMsg, resultDt, data }` |
| `/customers/*` | Unwrapped `data` |
| `/constants/*` | JSON array of `{ code, sort, name, … }` |
| Auth failures | Kayko EBM `{ status, message, error }` |

### Common result codes

| `resultCd` | Meaning |
|------------|---------|
| `000` | Success |
| `001` | No new data (sync-style pulls) |
| `910` | Parameter / totals validation error |
| `999` | Unknown error |

Full list: [Response Codes](/reference/response-codes).

### Common auth errors

| `error` | Meaning |
|-------------|---------|
| `API_KEY_REQUIRED` | Missing business key |
| `API_KEY_INVALID` / `INACTIVE` / `EXPIRED` | Bad or unusable key |
| `API_KEY_SCOPE_DENIED` | Missing required scope (e.g. `customers`) |
| `API_KEY_IP_DENIED` | Caller IP not allowlisted |
| `INTERNAL_TOKEN_REQUIRED` | Missing/wrong `X-API-Token` on `/initialize/*` |

## Local connectivity

The Mintlify docs proxy may not reach `localhost`. If playground calls to Local EBM fail from the cloud preview, call the same URL from your machine (cURL, Postman, or your app) using the samples on each page.
