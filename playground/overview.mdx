Switch to the **API Playground** tab and pick an endpoint from the sidebar. Each page has a pre-filled request body, auth headers, and a **Send** button.

## Before you start

<Steps>
  <Step title="Pick an environment">
    Use the **environment dropdown** on any playground page. Default: `http://localhost:3000/ebm`. Code samples use `{{baseUrl}}` and update when you switch.
  </Step>
  <Step title="Authenticate">
    | Routes | Header |
    |--------|--------|
    | Business routes (items, sales, …) | `Authorization: Bearer sk_…` or `x-api-key: sk_…` |
    | Initialization (`/initialize/*`) | Prefer `X-API-Token`; a business API key also works |

    See [API Keys](/concepts/api-keys) for business key setup.
  </Step>
  <Step title="Set tenant headers">
    Send `x-tin` and `x-branch-id` on proxied routes. List endpoints also need `x-last-request-date` (`YYYYMMDDHHmmss`). You do not send `ebm_url` in the body. Head-office writes (`POST /items`, `PUT /items/:item_code`, `POST /imports/confirm`, `POST /purchases/confirm`) require `x-branch-id: 00`.
  </Step>
  <Step title="Send">
    Edit the pre-filled body or query, click **Send**, and inspect the response panel.
  </Step>
</Steps>

## Response shapes

| Kind | Shape |
|------|-------|
| Device init | `{ resultCd, resultMsg, resultDt, data }` |
| Mapped Kayko routes | `{ message, data }` |
| Auth / gateway failures | `{ status, message, error }` |

Upstream `resultCd: "000"` = success. Full code list: [Response Codes](/reference/response-codes).
