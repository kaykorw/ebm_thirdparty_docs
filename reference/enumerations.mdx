Kayko write APIs accept **snake_case labels** (`payment_method: credit`, `status: approved`, `stock_type: sale`). Kayko maps those to VSDC codes below. Live tables: `GET /constants/taxes`, `/payment-modes`, `/stock-types`, `/refund-reasons`, `/import-item-statuses`, and the other constant routes.

## Tax Type

Used as `tax_type` on items and line items (upstream `taxTyCd`).

| Code | Name | Typical rate | Notes for integrators |
|------|------|--------------|------------------------|
| `A` | A-EX (Exempt) | 0% | Exempt supplies |
| `B` | B-18.00% | 18% | Standard VAT goods, most common |
| `C` | C (Zero-rated) | 0% | Zero-rated |
| `D` | D (Non-VAT) | 0% | Non-VAT |
| `E` | E (reserved) | 0% | Appears on live sale **headers** even though PDF v1.0.5 lists A–D only |
| `F` | F (Tourism tax) | often 3% in tables | **Do not** send `tax_type: F` on sale lines, live devices reject it |
| `TT` | TT (Tourism) | often 3% | Use on tourism sale lines with `tourism_tax: true` |

Live sale headers must include tourism rate keys `taxRtF` and `taxRtTt`. Kayko does **not** blindly send `3.00` for every TIN. Non-tourism businesses usually get JSON `null` rates; tourism businesses use catalog rates; overrides go through [`PUT /codes/tourism`](/api/codes) or sale-level `tax_rate_f` / `tax_rate_tt`.

## Product Type

Used as `item_type` when registering items (upstream `itemTyCd`).

Kayko accepts **text labels** on write APIs and returns those labels on read APIs. Legacy numeric codes remain accepted on input for compatibility.

| Upstream code | Kayko label | Name |
|---------------|-------------|------|
| `1` | `raw_material` | Raw Material |
| `2` | `finished_product` | Finished Product |
| `3` | `service` | Service (no automatic stock) |

## Transaction Type

Kayko sales always send live type `N`. Purchases accept `transaction_type` labels `normal`, `copy`, `proforma`, `training` (upstream `salesTyCd` / `pchsTyCd`).

| Code | Name | Usage |
|------|------|-------|
| `N` | Normal | Standard transactions (always use this for live sales) |
| `C` | Copy | Copy of an existing invoice |
| `P` | Proforma | Quote- not a tax document |
| `T` | Training | Practice- no legal effect |

## Stock In/Out Type

| `02` | Purchase |
| `03` | Return |
