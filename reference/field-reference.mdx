<Note>
  **Kayko requests use snake_case** (`item_code`, `invoice_no`, `payment_method`). Tables below are the **upstream VSDC** names Kayko sends after mapping. You do not send `tin` / `bhfId` in JSON, use headers `x-tin` and `x-branch-id`.
</Note>

### Kayko → VSDC (common)

| Kayko | VSDC |
|-------|------|
| `item_code` | `itemCd` |
| `item_classification_code` | `itemClsCd` |
| `item_name` | `itemNm` |
| `tax_type` | `taxTyCd` |
| `packaging_unit` / `packages` | `pkgUnitCd` / `pkg` |
| `quantity_unit` / `quantity` | `qtyUnitCd` / `qty` |
| `price` | `prc` |
| `supply_amount` | `splyAmt` |
| `taxable_amount` / `tax_amount` / `total_amount` | `taxblAmt` / `taxAmt` / `totAmt` |
| `invoice_no` | `invcNo` |
| `original_invoice_no` | `orgInvcNo` (**`0` on a normal sale or purchase**; original number on refunds) |
| `payment_method` | `pmtTyCd` |
| `remaining_quantity` | `rsdQty` (absolute remaining qty) |
| `use_tourism_tax` | `useTTaxYn` (items) / line tourism flag |
| `sale_purpose` | `salePurposeCd` (`01` resell, `02` consumption) |
| `rrp` | `rrp` (fuel regulated retailer price) |
| `regulated_discount` | `prftDcAmt` (fuel, 0–120) |

Live `saveSales` always includes **`taxRtF: 18`** and **`taxRtTt: 3`**. Tourism amounts are `ttAmt` / `totalTTAmt`. See [Tourism Tax and VAT on Fuel](/calculations/tourism-and-fuel).
