## Specification authority

The **Rwanda Revenue Authority (RRA)** defines EBM regulations and related technical requirements. This documentation describes the **Kayko EBM** third-party integration surface for EBM 2.1.

For regulatory enquiries, contact [RRA](https://www.rra.gov.rw).

## Reporting issues

To report errors or request clarifications:

1. Open an issue or pull request on the [documentation repository](https://github.com/kayko/documentation)
2. Reference the **endpoint** or **section** affected
3. Include a corrected example where applicable
